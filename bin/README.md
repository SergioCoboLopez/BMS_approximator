This folder contains all the codes needed to generate the results in the paper.
The codes can be tailored to your specific needs: different neural network architecture, number of functions, levels of Gaussian noise and so on.

The folder `no_degeneracy/` contains the Bayesian Machine Scientist, which is a repository in itself. The original repo is [here](https://bitbucket.org/rguimera/machine-scientist/src/no_degeneracy/) and the paper is [here](https://www.science.org/doi/10.1126/sciadv.aav6971).

The folder `slurm_scripts/` contains three slurm scripts to run the code `get_trace.py` on a cluster environment using the [slurm](https://slurm.schedmd.com/documentation.html) protocol.

The folder `ann_functions/` contains all the codes needed to generate the results to approximate ann-generated functions.

The folder `nguyen_functions/` contains all the codes needed to generate the results to approximate analytical nguyen functions.
